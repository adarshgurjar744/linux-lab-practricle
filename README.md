## ▶️ How to Run

```bash
# Clone the repo
git clone https://github.com/adarshgurjar744/linux-lab-programs.git
cd linux-lab-programs

# Make all scripts executable
chmod +x *.sh

# Run any script
./Linux_Lab_Practical_01_Hello_World.sh
```

## 🛠️ Requirements
- Linux / macOS / WSL / Git Bash
- bash shell (v4+)
- Standard Linux utilities: `grep`, `sed`, `awk`, `bc`
